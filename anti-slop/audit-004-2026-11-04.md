# Audit UI Undesign #004: information architecture and menu order

**Mode:** AFTER (session override). Read-only audit; no source code changed.

## Scope and coverage

Scope: shared Rust/egui editor shell for web and desktop, focused on top-bar actions, left/right panel navigation, toolbar order, and whether the left rail remains useful. Mobile redesign remains deferred. Current desktop/tablet screenshots and source were inspected; behavior in the dark theme was not.

Project conventions inspected: `AGENTS.md` (Rust/egui, real command behavior, project-owned glyphs), and `/workspace/undesign-ui-spec.md` (the older D3–D5 design spec). Parts of that spec conflict with the owner’s latest direction and should be amended along with any approved implementation. The owner clarified that Motion workspace/timeline stays separate, while only interaction animation settings move into Prototype.

Official Figma references reviewed: [editor overview](https://help.figma.com/hc/en-us/articles/15297425105303-Explore-design-files), [toolbar](https://help.figma.com/hc/en-us/articles/360041064174-Access-design-tools-from-the-toolbar), [right sidebar](https://help.figma.com/hc/en-us/articles/360039832014-Design-prototype-and-explore-layer-properties-in-the-right-sidebar), [zoom/view options](https://help.figma.com/hc/en-us/articles/360041065034-Adjust-your-zoom-and-view-options), and [navigation/left sidebar](https://help.figma.com/hc/en-us/articles/360039831974-Explore-the-navigation-bar-and-left-sidebar). Figma documents a Move → Frame → Shape → Pen → Text → Comment → Actions toolbar, a separate Dev Mode toggle, Design/Prototype inspector tabs, and separate navigation rail/sidebar regions. Its current docs put zoom percentage at the top-right of the right sidebar. The requested top-bar zoom location and Assets-as-puzzle-piece slot are explicit Undesign choices, not exact Figma conventions. The Assets glyph should be original project artwork, not a copied product asset.

## Verification

Passed: inspected the relevant current source for header, file rename/breadcrumb, zoom menu, left-tab routing, right inspector tabs, Prototype animation controls, Motion panel/timeline, toolbar groups, Dev Mode switcher, rail actions, and Assets shortcut. Inspected existing desktop/tablet previews. Read the project’s UI spec and `AGENTS.md`. Fetched the official Figma editor, toolbar, right-panel, zoom, and navigation guides.

Not verified: runtime menu interactions, the proposed new file/page menu, keyboard/screen-reader use, dark-theme states, and a live Figma session. No tests were run for this read-only audit.

## Verdict

Five MEDIUM information-architecture findings are ready for owner selection; no HIGH blocker was observed within this narrow, source-and-preview review. Per AFTER mode, no implementation begins until the owner chooses finding numbers.
