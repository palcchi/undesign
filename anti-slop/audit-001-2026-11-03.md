# Audit UI Undesign: alur masuk ke editor

**Tanggal:** 3 November 2026

## Yang ditinjau

Audit dibatasi pada halaman produksi [`/app/`](https://showcase-sigma-five.vercel.app/app/): layar masuk, keadaan sempit, startup WASM, kanvas kosong pertama, dan panel prompt juri. Halaman marketing `/showcase`, layar Home/Design/Motion/Agent lainnya, serta aplikasi desktop tidak ditinjau.

Shell memakai Vite 7, TypeScript, dan CSS variabel tanpa component library. Editor adalah Rust/egui yang dikirim sebagai WebAssembly. Kode memakai tema abu-abu terang/gelap sesuai pilihan terbaru pemilik. Catatan token D1 lokal masih menyebut aksen hijau; arahan monokrom terbaru dipakai sebagai acuan, dan dokumen itu tidak diubah.

Pedoman yang dibaca: [`AGENTS.md`](https://github.com/palcchi/undesign/blob/main/AGENTS.md), `ROADMAP.md`, `docs/gaps.md`, `docs/assistant-skills/design.md`, serta referensi workspace [`undesign-ui-spec.md`](/workspace/undesign-ui-spec.md) dan [`undesign-design-tokens.md`](/workspace/undesign-design-tokens.md). Referensi UI meminta reflow pada lebar menengah dan sempit serta state pressed yang terlihat. Skill khusus `better-accessibility`, `better-layout`, `better-writing`, `better-typography`, dan `better-colors` tidak tersedia, jadi domain tersebut tidak dinyatakan telah diaudit penuh.

| Domain | Bukti yang diperiksa | Hasil |

## Verifikasi

**Lulus:** `npm test` di `showcase/` lulus 23 dari 23 tes, tanpa kegagalan. Pada browser produksi 1440 x 757 px, iframe editor termuat. Tombol prompt juri membuka panel, mengubah `aria-expanded`, memindahkan fokus ke tombol tutup, lalu saat ditutup mengembalikan fokus ke tombol pembuka. Lebar 320 dan 720 px tidak mengalami horizontal overflow, tetapi editor memang tidak dibuat.

**Uji error:** di Chromium lokal, permintaan WASM diblokir sementara melalui DevTools. Hasilnya: marker runtime tetap ditemukan, `wasmBindings` tidak tersedia, loader internal tetap terlihat, dan tidak ada pesan error maupun tombol coba lagi. Setelah blok dilepas dan halaman dimuat ulang, WASM berjalan dan kanvas kembali ke ukuran 1240 x 630 px. Situs produksi tidak diubah oleh uji ini.

**Belum diverifikasi:** iOS Safari atau perangkat sentuh fisik, zoom browser nyata, navigasi keyboard penuh, tampilan runtime gelap secara menyeluruh, scroll chaining panel prompt juri, dan domain Accessibility/Layout/Writing/Typography/Colors secara penuh. Lebar 720 px adalah simulasi viewport efektif, bukan pengujian zoom browser sungguhan.

## Putusan

**Block:** masih ada 6 temuan HIGH. Putusan ini hanya untuk alur `/app/` yang ditinjau; Accessibility, Layout, Writing, Typography, dan Colors belum diaudit penuh karena skill domain khusus tidak tersedia.
