## Verifikasi

- `cargo fmt --all -- --check` dan `git diff --check` lulus.
- `cargo test -p undesign-ui-egui toolbar::tests`: **4 lulus, 0 gagal**. Pemeriksaan memastikan referensi state dan handler drag toolbar sudah dihapus.
- Build WASM release untuk preview lokal lulus. Modul WASM berukuran **24,200,923 byte**, di bawah batas proyek 25,165,824 byte.
- Chromium membuka runtime dengan HTTP 200, satu canvas, dan status `Undesign editor ready.`. Lebar dokumen sama dengan viewport pada 320 × 640, 1024 × 768, dan 1440 × 900.
- Klik mode Motion secara visual mengaktifkan segmen Motion dan menampilkan Motion Studio. Screenshot final kembali ke keadaan Design.
- Tidak ada page error atau request aset aplikasi yang gagal. Satu 404 `/favicon.ico` berasal dari root server preview Vite.
- [Preview desktop 1440 × 900](/workspace/undesign-ui-previews/20261103-qqs1XoEwTNZUikpz6owf4P-final-static-desktop-1440x900.png) ditinjau secara visual.
- [Preview tablet 1024 × 768](/workspace/undesign-ui-previews/20261103-qqs1XoEwTNZUikpz6owf4P-final-static-tablet-1024x768.png) ditinjau secara visual.

## Batasan

Paket opsional `craft-fonts` tidak tersedia di workspace, jadi preview memakai fallback font sistem. Versi `wasm-opt` yang terpasang tidak menerima satu flag bulk-memory dari Trunk; wrapper sementara menghapus flag itu hanya untuk preview. Wrapper tidak menambal source atau bundle produksi.

Dark theme dan seluruh interaksi editor di luar shell yang disentuh tidak diuji ulang sebagai audit penuh pada pass ini.
