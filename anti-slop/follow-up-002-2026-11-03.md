# Tindak lanjut audit UI Undesign #002: shell editor

**Status:** perubahan lokal untuk ditinjau. Belum di-commit, di-push, atau di-deploy.

## Perubahan pada temuan 4

Header editor kini menjadi satu baris bersama yang memuat nama file, breadcrumb file/halaman, avatar kolaborator, Play, dan Share. Panel kiri memakai tab **Pages | Layers | Assets** dengan footer jumlah layer dan layer terkunci. Pages dan Layers kini memiliki tampilan panel mandiri; drag layer ke halaman tetap didukung dengan membuka tab Pages saat pointer melewatinya.

Pada tablet 720 px, shell tetap memakai susunan desktop. Jalur compact ponsel yang sudah ada dipertahankan; tidak ada desain ulang ponsel pada pass ini. Penempatan Agent, Chat, dan Comment tetap di rail kiri; Comment tetap tidak ada di toolbar bawah; tab panel kanan tetap Design, Prototype, Motion. Perilaku maupun persistensi riwayat Chat/Comment tidak diubah.

Satu perubahan test-only mempersempit pencarian swatch Color pada tes plugin ke batas panel plugin, agar label Color milik background halaman tidak tertukar dengan kontrol plugin. Perilaku plugin tidak diubah.
