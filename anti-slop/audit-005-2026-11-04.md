## Hasil aturan UI

Tidak ada pelanggaran aturan Antislop yang dapat dibuktikan dari pemeriksaan sumber ini. Tidak ditemukan kontrol Motion yang jelas-jelas tidak bernama; kontrol khusus memakai helper yang mendaftarkan labelnya. Ini bukan audit visual/runtime menyeluruh.

## Opsi pengembangan untuk dipilih

### 1. Timeline sebagai daftar layer komposisi

`motion_panel.rs:284-297` membangun baris dari track yang sudah dianimasikan dan layer yang sedang dipilih di kanvas. Tanpa itu, timeline meminta pengguna memilih layer di kanvas terlebih dulu (`motion_panel.rs:320-323`). Dampaknya: timeline belum berfungsi sebagai layer stack utama seperti yang biasa ditemui di editor motion.

**Arah:** tampilkan layer komposisi di timeline dan sediakan pemilihan/penambahan track dari sana, sambil tetap memakai command engine yang ada.

### 2. Interpolasi dan easing keyframe

Model dan engine mengenal `Step`, `Linear`, dan `CubicBezier` (`crates/doc/src/motion.rs:141-153`; `crates/engine/src/cmd/motion.rs:101-124`), tetapi jalur UI menulis interpolasi linear (`crates/ui-egui/src/motion_panel.rs:542,596`). Keyframe yang dibuat lewat UI karena itu tidak mendapat kontrol easing/hold; editor kurva juga belum ada.

**Arah:** mulai dengan pilihan interpolasi dan preset easing untuk keyframe terpilih; kurva Bezier penuh bisa menjadi tahap berikutnya.

### 3. Membuat dan mengatur komposisi

UI membuat komposisi awal dengan nilai tetap 1920×1080, 30 fps, 300 frame (`motion_panel.rs:169-173`) dan metadata yang tampil hanya label (`motion_panel.rs:201-209`). Engine menyediakan create/delete, tetapi tidak ada command update untuk mengganti nama, ukuran, fps, atau durasi (`crates/engine/src/cmd/motion.rs:36-64`).

**Arah:** tambahkan pengelola komposisi dan satu command update yang tervalidasi serta undoable, lalu hubungkan field pengaturan ke command itu.

### 4. Membisukan track tanpa menghapus keyframe

Model menyimpan `enabled` dan evaluasi/preview menghormatinya (`crates/doc/src/motion.rs:56,112`; `crates/engine/src/cmd/motion.rs:331`), tetapi tidak ada command atau switch UI untuk mengubahnya. Stopwatch yang dimatikan menghapus track beserta keyframe (`motion_panel.rs:502-558`).

**Arah:** sediakan command `set-enabled` dan toggle mute per track; mematikan sementara tidak boleh menghapus keyframe.

### 5. Seleksi dan pengeditan banyak keyframe

State UI menyimpan satu keyframe terpilih dalam `Option<(track, frame)>` (`crates/ui-egui/src/lib.rs:643-646`), sedangkan alur set/move/remove beroperasi pada satu frame (`crates/engine/src/cmd/motion.rs:101-124`).

**Arah:** tambahkan seleksi rentang/multi-key dan operasi batch dalam satu langkah undo agar retiming beberapa keyframe tidak perlu dilakukan satu per satu.

## Menggunakan kode dari `unwritten-studio`

Repo [palcchi/unwritten-studio](https://github.com/palcchi/unwritten-studio) menyatakan `MIT OR Apache-2.0` (`Cargo.toml:9`; file `LICENSE-MIT` dan `LICENSE-APACHE`). Timeline-nya (`crates/ui-egui/src/panels/timeline.rs`, 4.548 baris) dan keyframe engine-nya (`crates/keyframe/src/lib.rs`, sekitar 1.023 baris) berguna sebagai referensi perilaku.

Namun, panel timeline itu terikat erat pada tipe `Comp`, `Layer`, `PropGroup`, `Property`, `LayerId`, command, dan state milik repo tersebut. Jadi kode itu bukan modul drop-in untuk model `Composition`/`AnimationTrack` Undesign. Cara yang lebih aman ialah mengadaptasi pola seperti layer/property tree, operasi banyak keyframe, dan dialog easing; bila mengambil potongan kode, pertahankan pemberitahuan lisensi/hak cipta dan verifikasi dependensinya. Jangan menyalin aset atau tampilan Adobe.

## Batas arsitektur yang harus dijaga

Mutasi tetap lewat command engine agar tervalidasi dan undoable; dokumen tetap data murni; preview animasi tetap bekerja pada salinan/hasil evaluasi dan tidak mengotori dokumen dasar atau undo history per frame (`AGENTS.md`; `docs/ai-motion-architecture.md:137`). Implementasi tidak boleh memindahkan Motion Studio ke Prototype—pengaturan animasi per-interaksi tetap di Prototype, sedangkan komposisi dan timeline tetap menjadi workspace Motion.
